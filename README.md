# Мои Плагины для Google Chrome

Самые полезные:
- switch tabs plugin
  Переключение на конкретные вкладки по хоткеям, открытие новой вкладки справа
- universal manga flipping plugin
  Позволяет вешать хоткеи <- -> на клик по указанным элементам на любых сайтах с помощью других хоткеев.
  См. в консоль для получения инструкции.
